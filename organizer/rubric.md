# 参考评分细则（Rubric）

> **发布与评判总则**：正式测评仅向被测模型挂载 `/workspace/` 目录（含 `TASK.md`、`input/` 与 `submission/`），严禁包含 `organizer/` 目录或草稿/旧版正文。科研能力评分与科学假设结论（正增益 / 无增益 / 负结果）分离并列记录，执行严谨的零增益或负结果可获满分。阶段二具体通过阈值、表位命中数字与终点公式均不写在题面中：能力评分不因模型报告选用略有不同的合理领域阈值（如 $\mathrm{pLDDT} > 75$ 或 $\mathrm{RMSD} < 2.0\text{ }\mathring{\mathrm{A}}$）扣分，跨模型横向指标由评测方基于原始坐标与逐样本原始明细表按本表统一标准离线重算。机器可读的官方阶段二阈值与三靶点参考表位见同目录 `reference_epitopes.json`。

| **2. 片段覆盖校准与拼接方法学** | | ① 在开发集上系统比较生成模型、片段长度与采样超参（如温度/噪声、采样预算）对天然界面逐残基骨架恢复率与计算开销的权衡，选型有据；<br>② 拼接与成环方法具备合理算法来源与真实跨片段溯源（至少两个独立片段，非全长重切）；<br>③ 自主建立物理合理的肽键化学几何与立体防碰撞过滤（如 C–N 键长、trans/cis $\mathrm{C_\alpha\text{–}C_\alpha}$ 间距、键角 $\alpha/\beta$、$\omega/\tau_C$ 平面二面角及主链/受体最小非键距离，具体范围核对表下参考几何阈值）；<br>④ 在固定预算（默认每表位 100 片段）下于检验集客观评估已知表位覆盖率与开销权衡，自主优选最优拼接方案（不设硬性 80% 门槛）。 | 以全长生成骨架冒充“单片段”或切开后原样拼接伪造片段组装。 |
| **3. 自主表位识别、化学拓扑与结构几何严谨性** | | ① **阶段二参考表位与精准度核验**（以下参考面均按重原子 $\le 5.0\text{ }\mathring{\mathrm{A}}$ 提取并经单受体 Shrake-Rupley 核验全量 $\mathrm{SASA} > 0$，PDB 作者编号）：<br>• **IL-7Rα**（`3DI3` 链 B，17–209；阻断 IL-7）：天然界面 19 残基 `B31, B33, B57–B59, B77–B83, B102, B104, B138–B139, B191–B193`（核心热点 `Val58, Leu80, Leu81, Ile82, Tyr139, Tyr192`；对照 `7OPB` 映射覆盖 `B58, B80–B84, B102, B104–B105, B138–B139, B191–B193`）。<br>• **TrkA**（`1WWW` 链 X，282–382；阻断 $\beta$-NGF）：天然 NGF 界面 28 残基 `X291, X294–X298, X300, X302–X304, X327, X333–X335, X343–X345, X347, X349–X350, X352–X355, X379–X382`；或邻近弯曲 $\beta$-片层阻断面（`7N3T`，21 残基）`X291–X300, X302–X304, X331, X333–X334, X343–X345, X347, X350`（核心热点 `Val294, Met296, His297, Pro302, Phe303, Leu333`；两参考面择一，两臂共用）。<br>• **PD-L1**（`4ZQK` 链 A，18–132；阻断 PD-1）：天然界面 22 残基 `A18–A20, A23, A26, A54, A56, A58, A63, A66, A76, A113, A115, A117, A119–A126`（核心热点 `Ile54, Tyr56, Gln66, Met115, Ala121, Asp122, Tyr123`）。<br>• **定量命中口径**：设 $S$ 为锁定表位、$R$ 为认可参考面，要求精准度 $\lvert S \cap R \rvert / \lvert S \rvert \ge 50\%$；弛豫设计位姿及每个计入通过的预测样本须按 $5.0\text{ }\mathring{\mathrm{A}}$ 重原子距离至少接触 3 个 $S \cap R$ 残基且命中占比 $\ge 50\%$；主动排除埋藏残基并阐明生物学与疏水斑块依据。<br>② 全流程保持 L-手性、无 Cys 与主链首尾酰胺键闭环拓扑不丢失，正确实现环肽有向循环移位去重与循环残基映射。<br>③ **私有校验单测（RMSD）**：受体与多肽同步任意刚体变换 $\rightarrow \mathrm{RMSD}_{\mathrm{bb}}$ 严格为 `0`；受体不动仅平移多肽 $4.0\text{ }\mathring{\mathrm{A}} \rightarrow \mathrm{RMSD}_{\mathrm{bb}}$ 严格返回 `4.0 Å`（防对多肽自拟合）；同时通过环肽重编号与失败样本测试。 | 阶段二刻意避开天然配体功能阻断界面、挑选背面非功能凹槽以抬高通过率，或两对比臂使用不一致的目标表位定义。 |
| **4. 序列优化、受控对照与预算核算** | | ① 合理调用并论证反折叠/可溶优化工具（如 `ProteinMPNN`、`SolubleMPNN`，以及对 `RFD4-Proteina` 等联合模型评估原生序列 vs 重设计消融）；<br>② 阶段二两臂保持对等调参、长度/拓扑配额、序列优化、自选表位与两阶段 `tmol` 弛豫配置（一致的受体约束、两阶段实际 `nstruct` 数、最低能量样本选取规则与分离态参考），并关注同底层生成器的弱基线局限；<br>③ 验证前锁定固定槽位与唯一最低能量参考结构；<br>④ 真实核算含 GPU/CPU、失败与弃用任务在内的全链路预算。 | 将终审双模型交叉验证提前偷跑且不计入总预算与分母、事后按终审结果替换提名候选、违背能量最低规则事后更换参考结构，或剔除空槽/失败样本缩小分母。 |
| **5. 预测语义、可开发性与统计推断** | | ① **核心考点（无 MSA 常识）**：核查保存的逐链预测输入配置——**受体合理使用 MSA/模板，而从头设计短肽不添加进化 MSA、结构模板或设计位姿约束**；<br>② 环肽正确编码主链闭环与 L-手性（如显式手性 SMILES 或共价键）并准确映射主链原子；<br>③ **官方离线重算通过阈值**：正确统一 `AlphaFold3` 与完整版 `ESMFold2` 的 `pLDDT` 尺度与原子聚合，自主设定合理领域验收标准并执行单样本联合判定；评测方离线重算统一口径为——**单模型 Pass**：同一样本同时满足 $\mathrm{pLDDT}_{\mathrm{pep}} > 70$、$\mathrm{ipTM} > 0.70$、$\mathrm{RMSD}_{\mathrm{bb}} < 2.5\text{ }\mathring{\mathrm{A}}$ 且满足维度 3 表位有效命中（固定 15 样本中 $\ge 1$ 个达标）；**高置信度 Pass**：同一样本同时满足 $\mathrm{pLDDT}_{\mathrm{pep}} > 85$、$\mathrm{ipTM} > 0.85$、$\mathrm{RMSD}_{\mathrm{bb}} < 2.5\text{ }\mathring{\mathrm{A}}$ 且命中表位；**双模型主验收**：同一候选在 `AlphaFold3` 与完整版 `ESMFold2` 中均达单模型 Pass（高置信度同理）；<br>④ **能量打分语义与私有单测**：正确按 $E_{\mathrm{complex}} - E_{\mathrm{receptor}} - E_{\mathrm{peptide}}$ 计算相互作用能、理解势能越负越有利且分离态定义全程一致；通过**私有单测**（两例复合物的总能量排序与相互作用能排序相反，核验代码按相互作用能排序）；<br>⑤ 理性选用并批判性分析短肽/环肽溶解度代理指标（认识 `SWI` 偏全长蛋白、`MahLooL` 侧重 18–50 aa 局限），提名前剔除极端劣质候选；<br>⑥ 用 `DSSP` / $(\phi,\psi)$ 等合理方法区分单链二级结构组成与候选池多样性并结合口袋偏好解释；<br>⑦ 同时报告全量与通过子集统计及逐靶点不确定性，避免 3 靶点过度推断并独立定位瓶颈环节（覆盖不足、接头几何损耗、闭环应变或序列偏移）。 | 向 `AlphaFold3` / `ESMFold2` 泄露设计结合位姿；为从头设计短肽错误提供天然蛋白 MSA/模板（扣本维核心分）；跨不同预测样本拼凑最优 `pLDDT`/`ipTM`/`RMSD` 判定通过。 |
| **6. 可复现与可审计性** | | ① 完整交付阶段一天然参考复合物坐标与原始片段、复算 `tmol` 能量输入配置、生成前锁定表位清单、终审预测前固定槽位提名 CSV（空槽留痕）、逐预测样本状态表、逐链输入配置及最小可复算坐标；<br>② 独立离线重跑 `run.py evaluate` 可从落盘证据完全还原报告中的统计分母、两臂指标与差值。 | `run.py evaluate` 直接输出硬编码/缓存汇总值而非基于落盘坐标与明细表离线重算。 |

> **参考几何阈值**：评测方按标准肽键化学几何与立体防碰撞合理范围核查（C–N 键长、trans/cis $\mathrm{C_\alpha\text{–}C_\alpha}$ 间距、键角 $\alpha/\beta$、$\omega/\tau_C$ 平面二面角、残基内主链键长及相邻/非相邻/受体最小非键距离；具体数值表由命题方单独维护）。
