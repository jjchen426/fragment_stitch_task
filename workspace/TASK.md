# 基于短片段生成与组装的多肽结合剂生成方法开发

本研究聚焦多肽结合剂（peptide binder）从头设计中的方法学问题：针对给定的靶蛋白表面表位，先生成大量靶点条件化的短肽结构片段，再经几何组装、序列设计与物理能量优化构建完整多肽（$5\text{–}20\text{ aa}$ 线性肽与主链首尾闭环肽），检验该路线在同等候选配额与计算预算下，能否比直接生成全长多肽产出更高比例的结构自洽、相互作用能评分有利的候选结合剂，并同步考察目标表位上的构象与二级结构分布特征。

主流蛋白质生成模型（如 `RFdiffusion`、`RFD4-Proteina`、`BoltzGen`）通常面向多种设计任务；尽管部分模型已支持多肽或环肽设计，其直接生成 $5\text{–}20\text{ aa}$ 线性肽与环肽时在复杂表位上的适配性和构象采样表现仍需系统检验（例如在部分体系中可能偏向较单一的规则二级结构）；而天然高亲和力多肽常在短序列内组合转角、延伸链、局部螺旋与环化约束以匹配靶点表面微环境。本研究检验如下假设：将全长多肽生成分解为“局部短片段采样 + 跨片段拼接/闭环 + 全链序列与能量优化”，能否凭借局部片段对表位微环境的高覆盖率改善复杂表位上的设计成功率与相互作用能表现。本研究先在去冗余的已知蛋白–多肽复合物基准集上定量校准短片段覆盖并建立组装方案，再在三个代表性靶点上围绕给定生物学功能目标与全长直接生成基线开展等预算受控对照比较。

本题为探索性研究任务，片段来源、采样策略、拼接算法、序列设计与具体实现由执行者自主探索确定。为保证不同路线在同一尺度下可比，统一约定以下范围边界、实验协议与配额约束：

1. **化学与拓扑范围**：设计多肽长度限定为 $L \in [5, 20]$，拓扑涵盖线性多肽与主链首尾酰胺键闭环肽（head-to-tail cyclic peptide），不含非天然氨基酸、D-氨基酸及任何侧链交联（包括二硫键闭环）。针对非共价结合设计体系，两条对比臂（无论是否执行序列重设计）在候选设计中均**不包含半胱氨酸（Cys）**，仅使用其余 19 种标准 L-氨基酸。候选身份由氨基酸序列与拓扑共同唯一确定，首尾闭环肽去重须合并保持主链方向的循环移位等价序列。
2. **公共受体坐标系、骨架 RMSD 与目标表位**：凡计算结合位姿骨架 $\mathrm{RMSD}_{\mathrm{bb}}$，均采用受体参考坐标系下的多肽主链（$\mathrm{N, C_\alpha, C, O}$）偏差（环肽允许在保持主链方向的前提下采用化学等价的循环残基对应）。阶段一界面残基定义为任意重原子距受体任意重原子 $\le 5.0\text{ }\mathring{\mathrm{A}}$ 的残基，并严格限定在参考复合物已知多肽的天然受体结合表位（仅向生成与拼接流程提供受体及表位残基清单）。阶段二仅提供三个靶点的单受体结构（位于 `/workspace/input/`：IL-7Rα、TrkA、PD-L1）与明确的生物学功能目标——分别设计能够**阻断 IL-7Rα/IL-7 互作**、**阻断 TrkA/NGF 互作**与**阻断 PD-L1/PD-1 互作**的多肽结合剂；由执行者自主确定并事前锁定各靶点的目标表位残基清单，并在报告中说明生物学与表面理化依据。阶段二弛豫后设计位姿及最终验证的预测复合物均须有效结合于各自锁定的目标表位。同一靶点在两对比方法间须使用完全相同的受体结构、对齐范围与锁定表位定义。
3. **非冗余基准数据集（用于阶段一）**：从实验解析的蛋白–线性肽与蛋白–主链首尾闭环肽复合物中筛选高质量结构（配体长度 $L \in [5, 20]$、标准 L-氨基酸、不含非天然修饰与侧链交联），构建总规模为 $20\text{–}40$ 个复合物的非冗余代表集（兼顾线性肽与环肽，保留完整入选与排除记录）。阶段二测试靶点及其同源或近重复条目不得进入阶段一调参或用作拼接模板；天然配体坐标仅可用于阶段一的离线评估。
4. **物理相互作用能与可开发性评估**：使用 `tmol`（基于 Rosetta 物理能量函数体系的 GPU 加速全原子打分与优化工具，输出以 Rosetta 能量单位 REU 计的全原子势能评分）计算复合物相互作用能评分 $\Delta E_{\mathrm{bind}}$。所有进入能量比较的全原子结构须执行统一的两阶段弛豫协议，力场分别采用 `beta_nov_2016`（内坐标弛豫，至少 40 次迭代）与 `beta_nov_2016_cart`（笛卡尔坐标全原子最小化，至少 200 次迭代）；两臂须事前统一单候选弛豫起点数、两阶段实际迭代数、受体约束策略与多起点选取规则，逐次记录实际完成迭代数与终止状态（未完成规定迭代的任务计入开销，并报告有效能量候选数、实际提名数与固定槽位数），以最终弛豫结构计算 $\Delta E_{\mathrm{bind}}$ 及非键碰撞统计。水溶性与可开发性评估在**提名前**完成，与结构自洽验证解耦且不设单一硬阈值，但提名候选不得出现明显极差的水溶性或显著疏水聚集/非键碰撞风险（可综合参考 `SWI`、`MahLooL` 等代理指标独立报告分布并说明筛查与排除依据）。同时定量统计候选的二级结构组成及候选集间的构象与序列多样性。
5. **序列设计**：序列生成与反折叠重设计方案由执行者自主确定，须遵守约束 1 的化学与拓扑资格，并在阶段二中保证两臂拥有对等的序列优化与调参机会。
6. **结构预测交叉验证与固定采样配额**：候选序列同时送入 `AlphaFold3` 与完整版 `ESMFold2` 进行复合物结构预测（预测阶段不得泄露设计结合位姿）。环肽预测须在输入中准确保持主链首尾酰胺键闭环与 L-手性，并建立预测结构到参考主链的明确原子映射。以两阶段弛豫后的设计结构为参考，在受体参考坐标系下计算多肽平均置信度 $\mathrm{pLDDT}_{\mathrm{pep}}$（统一为 $0\text{–}100$ 尺度，注明两模型原子聚合口径）、受体–多肽界面得分 $\mathrm{ipTM}$ 及骨架 $\mathrm{RMSD}_{\mathrm{bb}}$，由执行者结合领域规范建立合理的自洽验收与交叉验证标准并完整保存逐样本原始指标。默认每靶点每方法固定提名 200 个候选，每候选每模型固定运行 3 个随机种子、每个 seed 生成 5 个样本（共 15 个样本）；缩减配额仅采用命题方在 `/workspace/input/` 中预先公布的数值，统一适用于全部靶点、方法和参评提交。未填满的提名槽位计入通过率分母，预测失败或缺失样本保留在其所属候选的既定采样配额中并记为未通过。

在报告中，请分两阶段阐述方法建立、优选与受控比较，给出关键算法与评分准则的数学定义：

- **第一阶段（片段覆盖校准与拼接方法建立）**：在非冗余基准集的已知结合表位上，按去冗余受体簇事前划分开发集与检验集（默认每个表位生成 100 个短片段，具体预算以 `/workspace/input/` 配置为准）。系统比较不同生成模型（如 `RFdiffusion`、`RFD4-Proteina`、`BoltzGen` 等）、片段长度与采样超参数对**天然界面多肽逐残基骨架恢复率**（受体参考坐标系下逐残基主链 $\mathrm{RMSD}_{\mathrm{bb}} < 1.5\text{ }\mathring{\mathrm{A}}$ 与 $< 2.0\text{ }\mathring{\mathrm{A}}$）及计算消耗的影响，在未参与调参的检验集上报告最优片段来源与生成参数。在此基础上建立满足合理肽键几何与无严重立体碰撞的片段拼接与首尾成环方法（合格拼接产物须由至少两个独立生成的短片段组装而成并保留逐残基溯源记录）。**拼接方法不强求严格复刻天然多肽骨架**，亦不预设固定表位覆盖率门槛；请在检验集上定量报告化学合法完整拼接产物对已知受体结合表位残基的覆盖率（$5.0\text{ }\mathring{\mathrm{A}}$ 重原子距离，按各检验复合物等权汇总并同步报告逐复合物覆盖率及与计算开销的权衡，可选附加与天然配体骨架的参考对比），并据此自主选定阶段二使用的最优拼接与序列优化流程。
- **第二阶段（三靶点功能阻断设计的等预算受控对照）**：针对 IL-7Rα（阻断 IL-7 结合）、TrkA（阻断 NGF 结合）与 PD-L1（阻断 PD-1 结合）三个靶点，先自主确定并锁定各靶点目标表位，再在 $L \in [5, 20]$ 范围内开展线性肽与主链首尾闭环肽设计。对每个靶点，将第一阶段确定的“片段拼接 + 序列优化”方案与采用相同底层生成器的“全长多肽直接生成 + 对等序列优化”基线进行等预算受控比较（统一核算生成、组装搜索、序列设计、弛豫、提名前初筛及失败/弃用任务的全部开销；两组保持同等调参与优化机会，预算允许时可补充最强原生全长模型作为附加参考基线）。**每个靶点、每种方法在最终预测验证前固定提名 200 个去重候选**（或 `/workspace/input/` 预公布统一配额；两组保持相同的长度与线性/环肽拓扑配额，每个槽位验证前唯一锁定序列、拓扑与单一设计参考结构，禁止事后替换候选或更换参考位姿），采用完全一致的 `AlphaFold3`/完整版 `ESMFold2` 采样配额与两阶段 `tmol` 协议评估。

此外，须定量比较两路线在结构预测自洽表现、单链二级结构组成、候选集间构象与序列多样性（结合靶点口袋本身的构象偏好作解释性分析）、界面接触残基数、接头/闭环几何应变及 `tmol` 相互作用能分布上的差异（同时区分全部提名候选与自洽通过子集两套口径），报告逐靶点效应量与不确定性区间，实事求是地说明结论受 3 靶点样本量、预测模型偏差及无 Cys 标准 L-氨基酸范围限制的适用边界。若在受控等预算下片段拼接相对全长直接生成未呈现正增益或表现劣于基线，完成规定对照后须如实报告无增益或负结果，并结合两阶段定量数据独立定位瓶颈环节（严谨执行的负结果与正结果具有同等科学评估价值）。

靶点参考结构、可用模型环境与硬件/预算说明位于 `/workspace/input/`，工作目录为 `/workspace`。研究材料与可复现产物统一保存在 `/workspace/submission/`：

- `/workspace/submission/report.md`：独立可读的研究报告，涵盖基准集构建与去冗余证据、阶段一覆盖与参数优选、拼接/成环定义与算法来源、阶段二三靶点自主表位选择与依据、序列与两阶段 `tmol` 流程、阶段二受控对比与机理分析、全链路实际耗时与失败统计及适用边界。
- `/workspace/submission/results/results_stage1.json`：汇总基准集构成、入选/排除与去冗余统计、开发/检验集划分、各方案逐残基骨架恢复率/表位覆盖率/开销及最优超参；图表保存在 `/workspace/submission/results/stage1/`，并保留足以离线复算的天然参考复合物坐标、原始片段、拼接产物坐标与溯源记录。
- `/workspace/submission/results/results_stage2.json`：汇总阶段二各靶点锁定的目标表位残基清单及选择依据，以及两臂固定配额下的结构预测原始置信度/位姿分布、自主定义的单/双模型交叉验证通过统计、`pLDDT`/`ipTM`/`RMSD`/`tmol`$\Delta E_{\mathrm{bind}}$ 及溶解度代理指标的全量与通过子集统计、二级结构与多样性统计、槽位/失败统计及对比结论（注明单位、分母与相对证据路径）；图表保存在 `/workspace/submission/results/stage2/`。
- `/workspace/submission/results/candidates/`：按靶点与方法保存固定槽位提名清单（CSV，**每个固定槽位一行**，记录靶点、方法臂、状态/空槽原因、序列、拓扑、环肽规范表示、长度、提名前筛查记录与设计参考结构路径，拼接组附加来源片段溯源）。
- `/workspace/submission/results/candidates/relaxed/`：两阶段弛豫后的设计复合物结构文件及逐候选能量、迭代数、终止状态与碰撞明细表。
- `/workspace/submission/results/candidates/predicted/`：`AlphaFold3` 与完整版 `ESMFold2`**实际使用的逐链输入与推理配置**、原始置信度输出、环肽原子映射表、**逐模型×逐 seed×逐 sample 完整评价明细表**（含状态、原始置信度/位姿指标与失败原因）；完整预测结构（`.cif.gz` 或 `.pdb.gz`）可按存储预算选存，但每个成功预测样本须保留足以离线独立复算受体对齐、骨架 RMSD、表位接触与置信度的最小坐标与原始置信度字段。
- `/workspace/submission/code/`：完整代码与 `/workspace/submission/reproduce.md`（环境、权重路径、随机种子、预算核算与命令）。统一入口 `/workspace/submission/code/run.py` 支持 `evaluate --input-dir <已保存产物目录> --output-dir <输出目录>`（离线评估材料须含天然参考复合物坐标、复算 `tmol` 相互作用能所需的输入配置，以及生成前锁定的表位清单、终审预测前锁定的槽位清单与筛除/失败/弃用任务逐项开销记录；离线重算全部指标并生成 `<输出目录>/results/results_stage1.json` 与 `results_stage2.json`）及 `pipeline --input-dir <原始输入目录> --output-dir <输出目录>`（复现阶段一参数优选与阶段二完整流程）。
